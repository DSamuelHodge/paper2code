# Paper2Code

Runnable, teaching-first notebooks for machine-learning papers, one folder per paper. Each folder links to the paper, says whether official code exists, and includes a Colab notebook that rebuilds the paper's core method with real code and labels what comes from the paper versus what is a simplification.

|---|---|---|
